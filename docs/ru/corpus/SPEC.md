# Русский корпус для дообучения NER: задание автору

Ты пишешь короткие выдуманные русские тексты с разметкой персональных данных. Они пойдут на
дообучение модели, которая ищет персональные данные в сообщениях пользователей и в ответах
инструментов (почта, CRM, таблицы, логи), прежде чем текст уйдёт в языковую модель.

## Формат

Один документ — одна строка JSON в выходном файле:

```json
{"id": "<срез>-<номер>", "slice": "<срез>", "markup": "<текст с разметкой>"}
```

Разметка внутри текста: `{{ТИП|значение}}`. Типы:

| Тип | Что это |
|---|---|
| `PERSON` | имя человека в любой форме: ФИО, имя, фамилия, имя и отчество, инициалы, уменьшительное, обращение («насть», «юль», «Саня»), с маленькой буквы |
| `ORGANIZATION` | название компании, магазина, учреждения («ООО «Северный ветер»», «Сбер», «поликлиника № 3») |
| `ADDRESS` | адрес проживания или доставки целиком: индекс, регион, город, улица, дом, корпус, квартира; неформальный («на Садовую 14, кв 7», «Ленина 5-12») |
| `DATE_OF_BIRTH` | только дата рождения; любая другая дата — не размечается |
| `EMAIL` | адрес почты (только домены example.com, example.org, example.net, example.ru) |
| `PHONE` | телефон в любом виде |
| `ID_DOCUMENT` | паспорт, загранпаспорт, водительское, СНИЛС, ИНН, ОГРНИП, полис ОМС |
| `BANK_ACCOUNT` | номер счёта или карты |

Правила разметки:

- Имя размечается **целым словом в той форме, как написано**: `{{PERSON|Смирновой Ольге Петровне}}`,
  `{{PERSON|насте}}`, `{{PERSON|кузнецова}}`. Падежное окончание — внутри метки.
- Должности, роли и обращения без имени — **не** размечаются: «директор», «Арендатор»,
  «уважаемый клиент», «коллеги», «господин», «ИП» перед именем (`ИП {{PERSON|Гусейнова Л. Р.}}`).
- Город или улица без номера дома — не адрес: «живу в Казани», «склад на улице Ленина».
- Номер заказа, счёта на оплату, договора, накладной, артикул, сумма, обычная дата — не размечаются.
- Компании, бренды, продукты размечаются `ORGANIZATION`, даже если похожи на имя («Магнит»,
  «Лента», «Ozon»). Названия моделей и программ («Sonnet», «Excel») — не размечаются вовсе.
- Внутри `{{…}}` не может быть `{`, `}` и `|`.

## Данные

- Только выдуманные люди. Бери имена и фамилии из пула, который дан в задании, комбинируй
  свободно, склоняй как нужно. Не используй имена известных людей.
- Почта только на example.*; телефоны с 555 в середине (`+7 916 555-01-23`, `8 (495) 555-12-34`);
  номера документов и счетов — любые цифры подходящей длины.
- Тексты разные по длине (от одной строки до 10 строк), по стилю и по устройству. Не повторяй
  одну схему фраз.

## Чего нельзя

- Реальных людей, реальных адресов конкретных людей, реальных номеров.
- Медицинских диагнозов, политических и религиозных взглядов, сведений о судимости.
