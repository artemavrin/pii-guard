# Русский язык в PII Guard (наш форк)

Форк только для нас, PR авторам не готовим. Ветка `ru-pack`.

## Требования

1. Один человек в сессии — одна метка, в любом падеже и при любом способе упоминания
   («Смирнова Ольга Петровна», «Ольге Петровне», «Смирновой», «смирновой» в чате).
2. В ответе модели настоящее имя возвращается в том падеже, которого требует фраза.
3. Номера, документы и адреса в русском тексте маскируются правилами, а не только моделью.

## Исходная точка (2026-11-16, `develop` 143c1bd, без пакета `ru`)

Один диалог из пяти сообщений в одной сессии (`/v1/mask`, `language=ru`, быстрый режим):

| Что | Результат |
|---|---|
| Ольга Петровна Смирнова, 4 упоминания в разных падежах | 4 разные метки |
| Кузнецов, 2 упоминания | 2 разные метки |
| Адрес «г. Тверь, ул. Советская, д. 12, кв. 34» | не замаскирован |
| «смирновой и кузнецова» в чате, оба уже известны сессии | не замаскированы |
| Восстановление «письмо отправил [[Ольга]]» | «отправил Смирновой Ольги Петровны» (падеж из первого упоминания) |
| Восстановление «[[Кузнецов]]у» | «Алексей Кузнецову» |
| Паспорт, СНИЛС, телефон с «8» | замаскированы |

Скрипт: `docs/ru/e2e_session.py` (нужен запущенный `pii-guard serve`).

## Проверочный набор: до и после правил

`eval/fixtures/ru-smoke.jsonl`: 14 документов, 65 меток, 2 текста без ПДн. Быстрый режим
(правила + NER v4.2), `pii-guard eval --detectors rules,ner`:

| | Утечки | Частичные | Лишние маски | Согласованность меток |
|---|---|---|---|---|
| Без пакета `ru` | 4,8% | 3,2% | 6,1% | 92,1% |
| С пакетом `ru` (правила, подсказки) | 1,6% | 0% | 1,6% | 98,4% |

Только правила (без NER): утечки 90,5% → 52,4%, точность 100%. Остаток в быстром режиме:
имя с маленькой буквы в чате («насте») и «Ленина» в «складе на улице Ленина» (NER) — оба
для дообучения. Диагностика по документам: `docs/ru/diagnose.py`. Контрольные оценки других
языков (`python -m pii_guard.eval.gate`) не изменились.

## Устройство

Ядро хранит значение под нормализованной строкой и умеет приводить форму к начальной
только через хвост последнего слова (`InflectionMatcher.splits`). Русское ФИО склоняется
целиком, а люди упоминаются по частям. Поэтому два слоя.

### Слой 1. Личность: все формы человека — одна запись хранилища

- `RussianNameMatcher` (пакет `ru`): разбирает найденное ФИО на части (фамилия, имя,
  отчество) и падеж, приводит к именительному (pymorphy3; для неизвестных фамилий — правила
  pytrovich). Ключ записи — начальная форма полного ФИО.
- Частичное упоминание («Ольге Петровне», «Смирновой») привязывается к человеку сессии,
  если совпадают части в начальной форме и кандидат один. Если кандидатов несколько —
  отдельная запись (лучше лишняя метка, чем чужое имя в ответе).
- Слово с маленькой буквы, совпавшее с частью известного человека в любом падеже,
  маскируется (сейчас «смирновой» в чате утекает).

### Слой 2. Поверхность: модель видит «Персона_Женщина_7f3a», а не `[[PERSON_x]]`

Только для людей и только при `language=ru`; остальные типы остаются метками ядра.

- На выход: человек сессии показывается как `Персона_Мужчина_<id>` / `Персона_Женщина_<id>`,
  оба слова в падеже оригинала («Передай Персоне_Женщине_7f3a»). Пол — из имени (pytrovich).
- В системный промпт — заметка: за меткой настоящий человек, имя подставится в том падеже,
  в котором написана метка, поэтому склонять оба слова; как назвать человека, решает
  система; не упоминать метки и не выдумывать имён (текст — `NOTES["pm3"]` в
  `docs/ru/spikes/case_protocol_word.py`).
- На вход: падеж читается из формы слов метки, состав имени выбирается при восстановлении
  (в обращении — имя и отчество, если отчество известно; иначе как человек был назван).
  Восстанавливаются только части имени, известные сессии.
- Стриминг: держать хвост текста, пока он может оказаться началом метки («Персон…»).

Почему так: три замера на 30 заданиях (`docs/ru/spikes/README.md`, Claude Haiku).
Метка с тегами падежа — 14% неверных падежей; подставное имя — 0 ошибок, но требует
проверки совпадения с настоящими людьми в сессии; «Персона» с доработанной заметкой —
0 ошибок и не может совпасть с настоящим человеком по построению.

Известные слабые места:
- Предлоги перед именем не подстраиваются («с Смирновой», «о Орлове») — нужна правка
  предлогов при восстановлении (с/со, о/об, к/ко, в/во).
- Замер на одной модели; повторить на моделях Metobe.

Телефоны (правила, без модели): `8…`, `+7…`, `(495) …`, любые страны с `+`,
`79XXXXXXXXX`, `9XX XXX-XX-XX` — без подписи; слитные 10 цифр, городские 7 цифр и чужие
страны без `+` — только после подписи («тел.», «телефон», «моб.», «звонить»).

## Этапы

0. Стенд и исходная точка — сделано.
1. Проверочный набор `eval/fixtures/ru-smoke.jsonl` — сделано. Набор сессий с падежами для
   требований 1–2 — вместе с этапом 3.
2. Правила — сделано: ИНН, СНИЛС, ОГРН/ОГРНИП, счёт с БИК (контрольные суммы сверены с
   опубликованными значениями); паспорт, загранпаспорт, ВУ, полис ОМС рядом с подписью;
   телефоны с «8», госномера, адреса; `cues.tsv`, `references.tsv`. В ядре: «№» и «номер»
   в шаблоне номера заказа, рубль среди валют, русские слова в списках `ner_numbers.py`.
3. Слой 1 (личность) и слой 2 (метки «Персона_Мужчина_id» / «Персона_Женщина_id») —
   сделано, проверено на заглушке модели через шлюз (обычный ответ и поток):
   `src/pii_guard/languages/ru/names.py` (разбор и склонение имён, метки),
   `src/pii_guard/languages/ru/persons.py` (реестр людей сессии, привязка упоминаний,
   досканирование форм, восстановление, придерживание в потоке), тесты
   `tests/languages/test_ru_persons.py`. Правки ядра: `Span.lemma` и его учёт в
   `vault/entry.py::plan_spans`; `Gateway.mask` и `Gateway.restoring` в
   `gateway/service.py`; восстановление меток в `gateway/restore.py` (текст и аргументы
   инструментов); обёртка сессии в `chat.py`, `responses.py`, `messages.py`; русское
   пояснение в `gateway/placeholder_note.py`. Проверка без шлюза: `docs/ru/layer_check.py`;
   через шлюз: `docs/ru/mock_upstream.py`.
4. Заметки для LLM-детектора, подписи полей паспорта, бренды, стоп-слова.
5. Проверка соответствия (`pii-guard lang check ru`), оценки других языков не изменились.
6. Дообучение NER на остаток (имена без заглавной, неформальные адреса): корпус и разметку
   пишет Claude, обучение на JarvisLabs L4.

## Запуск стенда

```bash
uv sync --extra ner            # PyPI мимо локального прокси: env -u HTTPS_PROXY -u HTTP_PROXY
PII_GUARD_TENANT_KEY=$(openssl rand -hex 32) PII_GUARD_DEFAULT_LANGUAGE=ru \
  PII_GUARD_PORT=8797 uv run pii-guard serve
```
