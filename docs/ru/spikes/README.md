# Замер: падеж в метке или подставное имя

2026-11-16. Скрипт `case_protocol.py`, ответы модели — `case_protocol_answers.json`.

## Вопрос

Как показывать модели замаскированного человека, чтобы в её ответе имя восстановилось в
нужном падеже:

- **Метка с тегами**: `[[PERSON_7f3a|ж|фио|дат]]` — пол, состав имени, падеж. Модель сама
  ставит состав и падеж, каких требует её фраза.
- **Подставное имя**: «Иванова Анна Сергеевна» вместо «Смирнова Ольга Петровна». Модель
  склоняет его как обычное имя; падеж и состав читаются из формы (pytrovich).

## Как мерили

30 заданий, где человека надо упомянуть в другом падеже или составе, чем в сообщении.
Оба варианта на одних заданиях, по одному ответу. Отвечал Claude Haiku 5.5 чистым чатом
(`claude -p`, без инструментов). Каждое упоминание после восстановления оценено вручную:
верна ли форма имени в предложении.

## Результат

| | Метка с тегами | Подставное имя |
|---|---|---|
| Упоминаний | 50 | 53 |
| Неверный падеж | 7 (14%) | 0 |
| Не восстановлено технически | 0 | 0 |
| Ответов с дефектом из 30 | 9 (и ещё 2 с неестественным обращением) | 0 |

Дефекты варианта с тегами:

- Неверный падеж, 7 упоминаний в 6 ответах (№ 4, 12, 18, 20, 22, 28): чаще всего метка
  скопирована из сообщения с её падежом — «Заменить Кузнецов Алексей Викторович можно Максим
  Орлов», «Доволен Максим Орлов».
- Отказ (№ 6): «указана только метка, а не имя, поэтому не могу подставить имя и отчество».
- Одинокая метка отдельной строкой перед ответом (№ 7).
- Рассуждение о метках в ответе пользователю (№ 27): «Метка не поддерживает звательный
  падеж…».
- Состав не сокращён в обращении (№ 14, 15): «Уважаемая Белова Марина Игоревна» вместо
  «Уважаемая Марина Игоревна». Подставное имя модель сократила сама в обоих случаях.

Общее для обоих вариантов: предлог перед именем не подстраивается под настоящее имя
(«с Смирновой», «о Орлове»). Нужна отдельная правка предлогов при восстановлении.

## Вывод

Подставные имена. Оговорки: одна модель, один прогон, задания и оценка мои. Заметку о тегах
можно улучшать примерами, но разрыв 14% против 0% и отказы на более слабых моделях скорее
вырастут, чем исчезнут.

# Второй замер: придуманная фамилия и скобки

2026-11-16. Скрипт `case_protocol_synthetic.py`, те же 30 заданий, Claude Haiku 5.5.
Оценка автоматическая: совпала ли форма в ответе с одной из форм pytrovich.

- **Придуманная фамилия** (нет в словаре из 182 тыс. настоящих фамилий Natasha: Тавренов,
  Кеслов, Мирзубов, Ровдин, Зельтов, Бранцев), имя и отчество обычные.
- **То же в скобках**: `[[Анна Тавренова]]`, с заметкой «скобки сохраняй».

| | Придуманная фамилия | В скобках |
|---|---|---|
| Упоминаний | 50 | 52 |
| Форма не распознана | 0 | 0 |
| Скобки сохранены | — | 41 из 52 (79%) |

Находки:

- Придуманные фамилии модель склоняет так же правильно, как обычные.
- Скобки теряются в каждом пятом упоминании: как единственный признак подставного имени
  не годятся.
- Инициалы (№ 4): модель написала «Кеслову Д. А.», восстановилось «Кузнецову Д. А.» при
  настоящем «А. В.». Формы с инициалами надо строить и восстанавливать отдельно.
- Выдуманное отчество (№ 9, вариант со скобками): человек был назван без отчества, модель
  дописала отчество из примера в заметке. Восстанавливать можно только те части имени,
  которые известны о человеке; примеры в заметках не должны содержать имён из пула.

# Третий замер: метка-слово «Персона_Мужчина» / «Господин»

2026-11-16. Скрипт `case_protocol_word.py`, те же 30 заданий, Claude Haiku 5.5.

- `Персона_Мужчина_20c2` / `Персона_Женщина_7f3a`, склоняются оба слова;
- `Господин_20c2` / `Госпожа_7f3a`.

Падеж читается из формы слова («Персоне_Женщине» — дат/пр, по предлогу; «Господина» —
род = вин, у мужских имён эти формы совпадают). Состав имени метка не несёт: при
восстановлении берётся состав первого упоминания. Каждое упоминание оценено вручную.

| Неверный падеж | 7 | 0 | 1 | 0 |
| Отказ «имени нет» | 1 | 1 | 1 | 0 |

обратиться по имени и отчеству (№ 6), «отчество мне неизвестно» (№ 27).

## «Персона» с доработанным системным промптом

Два прогона по 30 заданий (`case_protocol_word.py run pm2`, `run pm3`), оценка вручную.

- **pm2**: «за меткой настоящий человек, система подставит имя в нужной форме; пиши метку
  как имя, обращайся по ней, не говори, что имя неизвестно». Отказы и рассуждения о метках
  исчезли, но модель перестала склонять («Договор заключён с Алексей Кузнецов») — 5 из 54:
  «в нужной форме» прочитано как «склонять не надо». Пример «Здравствуйте, Персона…»
  добавил приветствия, где их не просили.
- **pm3**: «система подставит имя ровно в том падеже, в котором ты напишешь метку; склоняй
  оба слова; как назвать человека — полностью, по имени и отчеству или по фамилии —
  система выберет сама». Без примера с приветствием. При восстановлении: после «Уважаемая»,
  «Здравствуйте», «Добрый день», «Привет» и в строке «Метка!» — имя и отчество, если
  отчество встречалось, иначе имя; в остальных местах — как человек был назван в сообщении.
  Если два слова метки в разных падежах, берётся падеж первого.

|---|---|---|---|---|
| Упоминаний | 53 | 54 | 56 | 103 |
| Неверный падеж после восстановления | 0 | 5 | 0 | 0 |
| Отказ «имени нет» | 1 | 0 | 0 | 0 |
| Рассуждения о метках | 1 | 0 | 0 | 0 |
| Неестественный состав имени | 3 | 1 | 0 | 0 |

В pm3 одна смысловая неточность модели: «Максиму Орлову пришло три письма» вместо «от
Максима Орлова» (№ 22); падеж восстановлен так, как написала модель.
